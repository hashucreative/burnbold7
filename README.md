# BURNBOLD HQ

**Dream Without Limits**

BURNBOLD HQ is a company workspace website prototype built using HTML, CSS and JavaScript.

## Features

- CEO login
- Employee account creation
- Employee profiles and profile pictures
- Task creation and assignment
- Company messaging board
- File uploads
- Basic CEO permission controls
- Dashboard

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Getting Started

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Log in using the demo CEO account.

## Important Notice

This is an experimental front-end prototype.

- Data is stored locally in the browser.
- Employee passwords are not securely protected.
- Accounts, messages and files are not synchronized between computers.
- CEO permissions are not enforced by a secure server.
- Do not use real passwords, confidential company information or sensitive files.

A backend, secure authentication and cloud database are required before using this as a real company workspace.
